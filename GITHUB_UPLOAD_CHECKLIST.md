# GitHub / Zenodo Upload Checklist

1. Create a new GitHub repository (suggested name: `argo-selective-prediction`).
2. Upload **the contents of this folder**, not the parent ZIP itself.
3. Edit `CITATION.cff.template` with the real author name(s) and GitHub URL.
4. Rename it to `CITATION.cff`.
5. Commit/push everything.
6. On GitHub, create a Release tagged `v1.0.0`.
7. Connect the repository to Zenodo and archive the release to obtain a DOI.
8. Replace the repository placeholder in the manuscript Data Availability Statement with the GitHub/Zenodo URL/DOI.
9. Do not upload the raw ARGO ZIP; link to PhysioNet instead.
